# Changelog

All notable changes to the Cabin Three FAQ site, newest first.

This project follows [semantic versioning](https://semver.org) — **MAJOR.MINOR.PATCH**:

- **MAJOR** — a change that breaks an existing guest-facing URL or removes a page with no fallback.
- **MINOR** — a new topic, feature, or content section.
- **PATCH** — copy edits, corrections, and small content additions.

**Breaking changes to date: none.** Every topic consolidation and slug rename has shipped with a redirect, so links that worked before still work today — which is why the site is still on a 1.x version.
